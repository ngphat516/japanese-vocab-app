# Frontend

Frontend của Japanese Vocabulary App sẽ được triển khai tại đây, cùng repo với
`apps/backend`. Hiện chưa viết giao diện hoặc khởi tạo framework frontend.

Backend local: http://localhost:8000. API contract và endpoint có tại
http://localhost:8000/docs. CORS mặc định cho phép http://localhost:3000.

Tài liệu chung ở [docs](../../docs) và hướng dẫn chạy toàn project ở
[README gốc](../../README.md).
